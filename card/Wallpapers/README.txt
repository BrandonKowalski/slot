# Wallpaper

Add .png files here. Pick one in Settings > General > Wallpaper.

Make it your screen size:

  Device         Size
  RG SP          720 x 480
  RG34XX         720 x 480
  RG34XXSP       720 x 480
  RG35XXSP       640 x 480
  RG35XX Plus    640 x 480
  RG35XX-H       640 x 480
  RG28XX         640 x 480

Other sizes are scaled to fill the screen and cropped from the centre.
