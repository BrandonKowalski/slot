slot.

A bespoke, GBA-only frontend for the Anbernic RG SP.

Download GitHub Repo

User guide

Browse the Carousel

Use L and R to cycle through your cartridges.

Insert and Play

A short tap of A loads the last save state.
Hold A instead and the game starts fresh.

Ejecting a Game

Hold MENU to eject the cart and land back on the carousel. A save state will be created on exit.

Save States

SELECT + R1 creates a save state.
SELECT + L1 loads the most recent.
Double tap MENU to open the save state picker.

Fast-Forward and Rewind

Hold R2 to fast-forward, or double tap to toggle it.
Hold L2 to go back in time.

Lid Detection

Closing the lid turns off the display. After three minutes, slot will create a save state and power off. The inserted game will resume with this save state on the next boot.

Anticipated Questions Answered

Will slot run anything other than GBA?
No.
This is almost perfect but needs _______. Will you add it?
No.
Does slot allow you to pair Bluetooth headphones?
No. Use the headphone jack.
Where do the games come from?
Your own legally obtained backups.
How do I add cart labels?
Drop a .png into Labels/ named after the rom.
For example, Metroid Fusion.gba matches Metroid Fusion.png.
Is there a GBA boot animation on game start?
Yes! Drop gba_bios.bin into BIOS/.
I have another question that isn't answered here.
No.
