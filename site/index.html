slot.

A bespoke, GBA-only frontend for the Anbernic RG SP.

Download GitHub Repo

User guide

Browse the Carousel

Use L and R to cycle through your cartridges.

Insert and Play

Tapping A loads the last save state.
Holding A starts the game fresh.

Ejecting a Game

Hold MENU to eject the cart.
On exit, slot creates a save state.

Save States

SELECT + R1 creates a save state.
SELECT + L1 loads the most recent.
Double tap MENU to open the save state switcher.

Fast-Forward and Rewind

Hold R2 to fast-forward, or double tap to lock it on.
Hold L2 to go back in time.

Lid Detection

Closing the lid writes a save state and turns off the display. Open it again and you're back in the game. Leave it shut for three minutes and slot powers off, resuming from that save state on the next boot.

Anticipated Questions Answered

Will slot run anything other than GBA?
No.
This is almost perfect but needs _______. Will you add it?
No.
Does slot allow you to pair Bluetooth headphones?
No. Use the headphone jack.
Where do the games come from?
Your own legally obtained backups.
How do I add cart labels?
Drop a .png into Labels/ with the same name as the ROM file.
For example, Metroid Fusion.png matches Metroid Fusion.gba.
Is there a GBA boot animation on game start?
Yes! Drop gba_bios.bin into BIOS/.
I have another question that isn't answered here.
No.
